Client Concierge · Build Plan

Claims & eligibility → review → assign → intake

A phased plan to generalize today's GLP1-only assignment pipeline into a type-driven intake engine: AMT and managers review claims/eligibility data and assign it to concierges, each assignment opens a typed intake record (GLP1 or non-GLP1) for the CC to work, and a registered member hands off to procurement. It starts with Phase 0 — the product/pricing/member masters migrated from Unifeyed, which everything else depends on.
